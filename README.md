# مستشار باهي (Bahi AI) — مساعد العطور الذكي

صفحة جوه المتجر على `bahi-perfumes.com/apps/bahi-ai`، فيها شات بالعربي بيساعد العميل:
يكتشف ذوقه، يفهم النوتات والعائلات العطرية، يسأل أي سؤال عن العطور، والأهم إنه يرشّحله
عطر باهي المناسب ويضيفه للسلة من نفس المحادثة.

الصفحة بتظهر بهيدر وفوتر المتجر وبنفس الهوية (كحلي/ذهبي، Reem Kufi وTajawal). كروت
المنتجات بتتسحب لايف من شوبيفاي: الصور والأسعار والمخزون والخصم وزرار "أضف للسلة".

## إزاي شغال

| الجزء | المصدر |
|---|---|
| النموذج | DeepSeek V4 Flash (`~deepseek/deepseek-v4-flash-latest`) عن طريق OpenRouter |
| بيانات عطور باهي | `catalog.json` (بيتولد من `../products_data.py` وتقييمات Fragrantica) — موجودة كلها في البرومبت |
| الأسعار والمخزون | `bahi-perfumes.com/products.json` (عام ومن غير مفاتيح، بيتحدّث كل 15 دقيقة) |
| معلومات العطور التانية | Scento Perfume API MCP (`https://www.scento.com/mcp`، من غير مفاتيح) |
| البحث على النت | Tavily، **آخر خيار** بس (للإصدارات الجديدة والأخبار)، بحد أقصى بحثين في الرد |

- **محصور في العطور بس:** أي سؤال برّه العطور (برمجة، واجبات، سياسة…) بيعتذر عنه في سطر
  ويرجّع الكلام للعطور. بيتجاهل أي محاولة تغيّر دوره أو تطلع تعليماته.
- **بيدفع للشراء:** كل ترشيح بيطلع معاه كارت المنتج + سؤال بسيط (50 ولا 100 مل؟) + العرض لو شغال.
- **أكواد الـ 25% مش بتتقال:** المستشار بيعرف بس الخصم التلقائي.
- الرد بيتكتب قدام العميل وهو بيتجهز (الصفحة بتسأل السيرفر كل 0.6 ثانية)، لأن App Proxy
  بتاع شوبيفاي مش بيسمح بالـ streaming المباشر.
- المحادثة بتتحفظ في متصفح العميل (localStorage)، لأن شوبيفاي بيشيل الكوكيز من الـ proxy.

## التكلفة والحماية من الاستهلاك

رسالة عادية بتتكلف حوالي **0.0002–0.003 دولار** (أول رسالة بعد فترة أغلى شوية، والباقي
أرخص بسبب الـ prompt caching). كل رسالة بيتكتب عنها سطر في الـ Logs على Render فيه
التوكنز والتكلفة والأدوات اللي اتستخدمت:

```
turn job=2cadc4e3 steps=2 tokens_in=21848 tokens_out=301 cost=$0.00022 tools=web_search secs=7.3
```

حدود ثابتة (تقدر تغيّرها من Environment في Render):

| المتغير | الافتراضي | معناه |
|---|---|---|
| `PER_CLIENT_10MIN` | 20 | رسايل للعميل الواحد كل 10 دقايق |
| `PER_CLIENT_DAY` | 120 | رسايل للعميل الواحد في اليوم |
| `GLOBAL_PER_MIN` | 40 | كل العملاء مع بعض في الدقيقة |
| `GLOBAL_PER_DAY` | 3000 | **سقف يومي** لكل الرسايل (أقصى صرف يومي تقريبًا 3000 × 0.003 = 9 دولار، والعادي أقل بكتير) |
| `MAX_OUTPUT_TOKENS` | 1200 | أقصى طول للرد |
| `MAX_AGENT_STEPS` | 5 | أقصى عدد استدعاءات للنموذج في الرد الواحد |
| `MAX_WEB_SEARCHES` | 2 | أقصى عدد بحث على النت في الرد الواحد |
| `MAX_USER_CHARS` | 800 | أقصى طول لرسالة العميل |

ويُفضّل كمان تحط حد صرف شهري على المفتاح نفسه من OpenRouter (Settings → API Keys → Limit).

## النشر

### 1) Render

1. ارفع الفولدر ده (`bahi-ai`) كـ repo لوحده على GitHub (نفس طريقة `order-intake`).
2. في Render: **New → Blueprint** (أو Web Service) واختار الـ repo. هيقرأ `render.yaml`
   (`gunicorn app:app --workers 1 --threads 16`). **لازم worker واحد بس**، لأن الردود والحدود
   متخزنة في الذاكرة.
3. في **Environment** ضيف:
   - `OPENROUTER_API_KEY`: نفس قيمة `bahi_openrouter_key` اللي على جهازك
   - `TAVILY_API_KEY`: نفس قيمة `tavily_api_key`
   - `SHOPIFY_PROXY_SECRET`: الـ Client secret بتاع تطبيق شوبيفاي اللي عليه الـ proxy (الخطوة 2)
4. بعد الـ Deploy هتاخد رابط زي `https://bahi-ai.onrender.com`. لو فتحته مباشرة هيرجّع 401،
   وده طبيعي: الصفحة بتشتغل بس لما الطلب ييجي من المتجر.

### 2) Shopify App Proxy (عشان الرابط يبقى `bahi-perfumes.com/apps/bahi-ai`)

الـ proxy لازم يبقى تابع لتطبيق متسطّب على المتجر. ينفع تستخدم التطبيق اللي عندك أصلًا
(بتاع `SHOPIFY_AI_CLIENT_ID`)، وساعتها `SHOPIFY_PROXY_SECRET` هو نفس قيمة `SHOPIFY_AI_PASS`.
وينفع تعمل تطبيق جديد مخصوص له.

من **Dev Dashboard → التطبيق → Versions/Configuration → App proxy**، أو بـ Shopify CLI في
`shopify.app.toml`:

```toml
[app_proxy]
url = "https://bahi-ai.onrender.com"
prefix = "apps"
subpath = "bahi-ai"
```

وبعدها `shopify app deploy`. اعمل release للنسخة الجديدة واتأكد إن التطبيق متسطّب على المتجر.
افتح `https://bahi-perfumes.com/apps/bahi-ai` وجرّب.

### 3) نافذة الشات في كل صفحات المتجر

زرار "اسأل باهي" تحت على الشمال في كل صفحة. على الكمبيوتر بيفتح نافذة شات عائمة، وعلى
الموبايل بيفتح الشات بالشاشة كلها. النافذة فيها زرار يفتح صفحة الشات الكاملة، والمحادثة
واحدة في الاتنين.

- الشات جوه النافذة هو `/apps/bahi-ai?embed=1` (نفس السيرفر، من غير هيدر وفوتر المتجر)، وبيتحمّل
  بس لما العميل يدوس على الزرار، فالصفحات مبتتقلش.
- لو العميل نقل لصفحة تانية والرد لسه بيتكتب، الرد بيكمل في الصفحة الجديدة.
- "أضف للسلة" من النافذة بيحدّث عدّاد السلة في هيدر المتجر.
- **التركيب:** بعد ما السيرفر ده يتنشر على Render، شغّل من فولدر `shopify`:
  `python apply_ai_widget.py` (بياخد نسخة احتياطية من الثيم الأول). وللشيل:
  `python apply_ai_widget.py --remove`.
- الكود في `shopify/theme_src/snippets/bahi-ai-widget.liquid`. لو عدّلته، شغّل السكريبت تاني.
- معاينة على جهازك: `http://127.0.0.1:5055/dev/widget` (و`?demo=1&open=1` لمحادثة جاهزة).

### 4) زرار في هيدر المتجر

**Online Store → Navigation → Main menu → Add menu item**: الاسم `مستشار باهي`، والرابط
`/apps/bahi-ai`.

### 5) UptimeRobot

اعمل Monitor من نوع HTTP(s) على `https://bahi-ai.onrender.com/healthz` كل 5 دقايق، عشان
السيرفر ميناموش (لو نام، أول زيارة بعدها ممكن تطلع صفحة خطأ من شوبيفاي).

## التشغيل على جهازك (للتجربة)

```
pip install -r requirements.txt
set BAHI_AI_DEV=1
python app.py
```

وافتح:
- `http://127.0.0.1:5055/dev`: الصفحة لوحدها (من غير هيدر المتجر)
- `http://127.0.0.1:5055/dev?demo=1`: محادثة جاهزة فيها كروت، **من غير ما تصرف أي رصيد**
- `http://127.0.0.1:5055/dev?reset=1`: تمسح المحادثة

المفاتيح بتتقري من متغيرات الجهاز (`bahi_openrouter_key` و`tavily_api_key`)، لو VS Code
أو التيرمنال اتفتح بعد ما اتعملوا. `BAHI_AI_DEV=1` بيلغي التحقق من توقيع شوبيفاي، فـ
**متحطوش أبدًا على Render**. وزرار "أضف للسلة" بيشتغل على المتجر الحقيقي بس.

## التعديلات المعتادة

- **غيّرت حاجة في العطور** (`products_data.py` أو ملفات التقييمات): شغّل `python build_catalog.py`
  وارفع `catalog.json` الجديد.
- **عرض جديد:** غيّر `OFFER_PCT` و`OFFER_END` و`OFFER_TEXT` في Render. العرض الحالي (20% لحد
  30 نوفمبر) بيقف لوحده بعد `OFFER_END`، والمستشار بيبطّل يذكره. الخصم اللي على الكروت
  بييجي من `snippets/bahi-offer.liquid` في الثيم، زي باقي صفحات المتجر.
- **الشحن المجاني:** `FREE_SHIPPING_TEXT`.
- **شخصية المستشار وقواعده:** `prompts.py`.
- **النموذج:** `OPENROUTER_MODEL` (الافتراضي بيمشي دايمًا مع أحدث نسخة من DeepSeek V4 Flash).

## الملفات

| الملف | الدور |
|---|---|
| `app.py` | الصفحة (Liquid) و API الشات و `/healthz` و `/dev` |
| `agent.py` | الـ agent: OpenRouter + الأدوات + تشغيل الرد في الخلفية |
| `prompts.py` | تعليمات المستشار + كتالوج باهي + الأسعار والعرض لايف |
| `catalog.py` / `catalog.json` / `build_catalog.py` | بيانات عطور باهي والأسعار |
| `scento.py` | عميل Scento MCP |
| `web_search.py` | بحث Tavily |
| `proxy_auth.py` | التحقق من توقيع App Proxy |
| `limits.py` | حدود الاستخدام |
| `net.py` | كل طلبات النت بحد أقصى للوقت (عشان مفيش رد يعلّق للأبد) |
| `templates/` و `static/` | الواجهة (الصفحة، ونسخة النافذة `embed.html`) |
